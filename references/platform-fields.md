# YouMind listing fields

Use the live creation page when it provides stricter requirements. The following fields and limits come from the current creator form supplied by the user.

| Order | Field | Requirement |
|---|---|---|
| 1 | Avatar | Required visual identity; use a square image |
| 2 | Skill name | Unique, concise, recognizable; no more than 40 characters |
| 3 | Subtitle | Positioning, function, or audience; no more than 60 characters |
| 4 | Instructions | The complete operating prompt; may contain multiple instruction blocks |
| 5 | Input prompt | Tell users what to provide when running the Skill; no more than 200 characters |
| 6 | Showcase | Zero to four items; default to one cover plus representative output examples |
| 7 | Description | Explain function, inputs, outputs, use cases, and differentiator |

## Copy rules

- Prefer a clear functional name over an opaque brand name. Use a memorable phrase only when the function remains obvious.
- Write the subtitle as a concrete promise, not a restatement of the name.
- Make the input prompt actionable. Include one short example only when it removes ambiguity.
- Preserve user-supplied instructions exactly when requested. Do not normalize punctuation, wording, line breaks, or placeholders inside the protected block.
- Describe what the Skill reliably produces. Do not claim publication, approval, or capabilities that were not verified.
- Do not add fields that are absent from the current form unless the user asks for optional marketplace strategy.

## Character-count verification

Count Unicode characters rather than bytes. Report the count beside each constrained field during QA, but omit the count from the copy-paste value itself.
