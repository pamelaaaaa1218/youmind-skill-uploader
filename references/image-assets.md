# Image asset production

Create images with the current Agent's installed image-generation skill. The tool's own instructions govern generation and editing mechanics; this reference governs YouMind asset composition and delivery.

## Default deliverables

| Asset | Canvas | Purpose |
|---|---:|---|
| Avatar / marketplace thumbnail | 1:1, preferably 1024 x 1024 | Recognizable identity in small lists and chips |
| Detail cover / first showcase | 16:9, preferably 1600 x 900 | Explains the Skill's value on its detail page |
| Additional showcases | 16:9, up to three more | Demonstrates distinct representative results |

If the image tool cannot render these exact pixels, request the correct aspect ratio at its highest practical resolution, then crop or resize locally without stretching. The live upload validator wins if YouMind changes its requirements.

## Avatar

- Convert the Skill's capability into one bold visual metaphor.
- Keep the subject inside the central 70% safe area.
- Use a strong silhouette, two to four colors, and high contrast.
- Avoid small text. Prefer no text unless one large, exact character is essential and verified.
- Avoid generic sparkle-only AI icons, screenshots, app mockups, excessive detail, random letters, and watermarks.
- Inspect at 64 x 64. If the concept disappears, simplify and regenerate.

## Cover and showcases

The first 16:9 image should show the transformation clearly: input or problem, the Skill's action, and a usable result. Do not turn it into a dense UI screenshot.

- Keep important content inside an 8% edge-safe area.
- Use the same palette, shapes, texture, and visual language as the avatar.
- Show real representative output rather than a generic mood board.
- Generate only examples that demonstrate materially different use cases; one strong example is better than four repetitive ones.
- Do not add logos, mascots, or brand marks the user did not provide.
- Avoid unreadable microcopy, random text, fake signatures, copyrighted characters, and watermarks.

## Generation brief structure

For each asset, specify:

1. intended use and aspect ratio;
2. core metaphor and subject;
3. composition and thumbnail hierarchy;
4. palette and medium;
5. exact text, if any;
6. invariants and avoid list.

Save the final briefs with the assets so another Agent can reproduce or revise them.

## Visual QA

Check:

- actual pixel dimensions and aspect ratio;
- correct subject and intended metaphor;
- no malformed or unintended text;
- no watermark or unrelated logo;
- avatar readability at thumbnail size;
- cover readability after common center-cropping;
- consistency across all showcase assets.
